## Mapeamento de Steps Gherkin para Flutter

| Gherkin (Usage) | Flutter Function |
| --- | --- |
| `O usuário volta a tela` | `oUsuarioVoltaATela` |
| `O usuário faz scroll ate o componente {'key' ou 'text}` | `oUsuarioFazScrollAteOComponente` |
| `O usuario espera {seconds} segundos` | `oUsuarioEsperaSegundos` |
| `O usuário digita {'input'} no campo {'key'}` | `oUsuarioDigitaNoCampo` |
| `O usuário clica no componente da key {'key'}` | `oUsuarioClicaNoComponenteDaKey` |
| `O usuário clica em {'text'}` | `oUsuarioClicaEm` |
| `O checkbox {'key'} esta com status {false}` | `oCheckboxEstaComStatus` |
| `O aplicativo não está na rota {'/route'}` | `oAplicativoNaoEstaNaRota` |
| `O aplicativo está na rota {'/route'}` | `oAplicativoEstaNaRota` |
| `As permissões foram aceitas` | `asPermissoesForamAceitas` |
| `O usuário ver a mensagem {'text'}` | `oUsuarioVerAMensagem` |
| `O usuário não ver a mensagem {'text'}` | `oUsuarioNaoVerAMensagem` |
| `O usuário loga na conta padrão` | `oUsuarioLogaNaContaPadrao` |
| `O usuário faz o logout` | `oUsuarioFazOLogout` |
| `O usuário fecha o bottom sheet` | `oUsuarioFechaOBottomSheet` |
| `O usuário fecha o dialog` | `oUsuarioFechaODialog` |
| `O usuário loga com username {'username'} e senha {'password'}` | `oUsuarioLogaComUsernameESenha` |
| `O usuário deleta a sua conta com username {'username'} e senha {'password'}` | `oUsuarioDeletaASuaContaComUsernameESenha` |
| `O usuário digita a sua senha {'password'}` | `oUsuarioDigitaASuaSenha` |
| `O usuário abre a aba de configurações` | `oUsuarioAbreAAbaDeConfiguracoes` |
| `O app está recém instalado` | `oAppEstaRecemInstalado` |
| `O app está com intro concluída` | `oAppEstaComIntroConcluida` |
| `O aplicativo está atualizado` | `oAplicativoEstaAtualizado` |
| `O aplicativo é inicializado` | `oAplicativoEInicializado` |
| `É criado um usuário via endpoint com username {'username'} e senha {'password'}` | `eCriadoUmUsuarioViaEndpointComUsernameESenha` |
| `O botão com key {'key'} fica habilitado` | `oBotaoComKeyFicaHabilitado` |

> Observação: algumas strings de uso podem ter diacríticos ou variações menores entre arquivos; a tabela usa as strings exatas conforme comentadas nos arquivos.
