# Domain Use-Cases

Propósito
- Contratos de casos de uso no domínio: entrada/saída, regras de negócio.

- Conteúdo
 - UseCase: NomeDoUseCase
  - Objetivo/escopo
  - Entrada/Saída (DTOs simples)
  - Fluxo principal
  - Falhas/erros esperados
  - Dependências (repository, service)
  - Testes sugeridos
