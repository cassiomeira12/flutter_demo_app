# OpenCode — Visão Geral do Projeto

Propósito
- Fornecer uma fonte única de verdade sobre a arquitetura, padrões, contratos entre domínios e instruções de contribuição do OpenCode.

Público-alvo
- Engenheiros novos e existentes
- Contribuidores externos
- Arquitetos de software e gerentes de produto

Escopo
- Abrange as camadas domain, data, infra, presentation, design_system e guidelines de contribuição.
- Descreve padrões de código, contratos entre pacotes, e diretrizes de documentação.

Princípios-Chave
- Clareza: decisões e contratos devem ser compreensíveis rapidamente.
- Consistência: usar templates padronizados para entidades, modelos, use cases, serviços, etc.
- Evolutividade: docs devem apoiar evolução de código sem travar mudanças estruturais.
- Governança aberta: owners por área, revisão de docs integrada ao fluxo de PR.

Conteúdo Principal
- Arquitetura de alto nível, padrões de comunicação entre pacotes, e diretrizes de contribuição.
- Referências rápidas para templates de documentação e exemplos de entidades/modelos.

Referências
- links para templates em docs/patterns e guia de contribuição
