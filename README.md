# Flutter Demo App

O **Flutter Demo App** é a base para qualquer aplicação Flutter deste ecossistema. Ele já inclui toda uma estrutura de código pronta, seguindo Clean Architecture e modularização, facilitando o desenvolvimento de novos apps.

## Estrutura e Módulos Prontos

O projeto já vem com módulos essenciais implementados, prontos para uso e customização:

- **Login**: Fluxo completo de autenticação de usuários.
- **Signup**: Cadastro de novos usuários.
- **Home**: Tela inicial e navegação principal.
- **User Data**: Gerenciamento e exibição de dados do usuário.

Além disso, a estrutura do projeto já contempla integração facilitada com outros módulos e features, como analytics, admin, notificações, etc.

## Como usar

1. Clone este repositório e utilize como base para seu novo app.
2. Aproveite os módulos prontos e adicione novas features em `/packages` conforme necessário.
3. Siga as convenções de arquitetura e modularização descritas em `ARQUITETURA.md`.
